2. Briefly describe how TLS provides confidentiality and integrity
Explanation:
Confidentiality: TLS uses symmetric encryption (AES) to encrypt data transmitted between client and server, ensuring that eavesdroppers cannot read the content. The symmetric session key is securely exchanged using asymmetric encryption (RSA or ECDH) during the handshake.

Integrity: TLS ensures data integrity with message authentication codes (MACs) or authenticated encryption (AEAD), which detect any tampering during transmission. If a message is modified in transit, the recipient can detect it and reject the data.
In short, TLS combines encryption for secrecy and MACs for tamper detection to secure communications
